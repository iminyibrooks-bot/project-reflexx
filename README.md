# Project Reflex - Last-Mile Logistics Tracking System

Reflex is an event-driven last-mile delivery tracking system designed for small retailers, dispatchers, and riders.

## System Architecture & Team Modules
- `apps/backend`: Node.js/Express API, PostgreSQL schema, WebSockets (Brooks)
- `apps/retailer-portal`: Retailer order creation UI (Cess)
- `apps/dispatcher-dashboard`: Dispatcher queue & rider assignment board (Joyce)
- `apps/rider-pwa`: Rider scanner and delivery state management (Wangari)
- `docs`: System documentation, trade-off logs, and architecture diagrams (Jerry)
